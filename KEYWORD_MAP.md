## Cannibalization and on-page use

- Keep `/` as the broad brand overview; use `/prodentim` for label, directions, and ingredient-evidence limits.
- Use `/reviews` for editorial evaluation, complaints/safety limitations, and whether the product's effects have been established.
- Reserve current offer, cost, checkout, and refund topics for `/buy-now` and `/official-website`.
- Keep the FAQ answers visible in HTML. No query phrase needs to be repeated unnaturally across all pages.
- Use the seller's current checkout/package documentation and Search Console data in a future refresh before publishing numerical prices or claiming measured search demand.

## Answer-first, source and discovery plan

- Keep each topic on its mapped canonical page; link related pages with descriptive internal anchors instead of duplicating whole keyword sections across every page.
- Use a short, direct answer near the start of the relevant page and keep the supporting explanation, evidence limitation and source links visible in server-delivered HTML.
- The pricing, refund and usage FAQs identify seller claims as seller claims. Research text identifies strain/dose/formulation limits. Review content does not manufacture ratings or testimonials.
- Images already used in product and package sections are labeled as illustrative where the actual formula, package terms or price cannot be independently verified. Keep descriptive alt text and preserve image dimensions.
- IndexNow can notify Bing and participating search engines of changed URLs once the root key file is deployed. A successful notification confirms receipt only; it does not guarantee crawl, indexing, or rankings. Google URL inspection/indexing requests remain a Search Console action.
- This audit did not verify live Google/Bing rankings or current keyword demand. Revisit the map with first-party Search Console and Bing Webmaster Tools query/impression data after collection.
